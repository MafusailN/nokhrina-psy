# Сайт-визитка · психолог Юлия Нохрина

Статичный одностраничник: HTML + CSS + чистый JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, заливается на любой хостинг (GitHub Pages,
Netlify, Vercel, обычный хостинг с FTP) простым копированием папки.

```
index.html
assets/
  css/styles.css
  js/main.js
  img/            ← сюда фотографии
```

## Что нужно заменить перед публикацией

| Где | Что |
|---|---|
| `assets/img/portrait.jpg` | ✅ взято с Avito (384×480 — стоит заменить оригиналом, см. ниже) |
| `assets/img/about.jpg` | квадратное фото для блока «Обо мне» — см. `tools/crop-avatar.ps1` |
| `assets/js/main.js`, `CONFIG` | адрес формы и запасная почта |
| `index.html`, блок «Или напишите напрямую» | ссылка на Telegram и e-mail |

Пока фото не положены, на их месте показывается аккуратная заглушка — сайт не ломается.

### Фото

`portrait.jpg` скачан из объявления на Avito и обрезан под 4:5 (водяной знак срезан).
Но Avito отдаёт превью 640×480 — для первого экрана это впритык, на телефонах с
Retina-экраном будет чуть мягко. Лучше попросить у Юлии оригинал этого кадра и
положить его на то же место — размером хотя бы 1200×1500.

`about.jpg` готовится скриптом `tools/crop-avatar.ps1`: сохраните фото в
`assets/img/about-raw.jpg`, запустите скрипт — он обрежет кадр под 4:5 (900×1125)
и срежет нижнюю полосу с реакциями и кружками сторис. Если рамка съедет, в начале
скрипта есть коэффициенты `CUT_BOTTOM / CUT_TOP / SHIFT_X`.

## Форма записи

Заявка уходит на почту через [Formspree](https://formspree.io) — бесплатного тарифа
(50 заявок в месяц) для визитки хватает, свой сервер не нужен.

1. Зарегистрироваться на почту Юлии.
2. **New form** → скопировать адрес вида `https://formspree.io/f/abcdwxyz`.
3. Вставить его в `assets/js/main.js`, строка `ENDPOINT`.
4. Отправить тестовую заявку и подтвердить адрес в письме от Formspree.

Пока `ENDPOINT` не заменён, форма работает в запасном режиме: открывает почтовый
клиент с уже заполненным письмом. Для боевого сайта так оставлять не стоит.

В форме есть скрытое поле-ловушка `_gotcha` — Formspree отсекает по нему ботов.

## Дублирование в Telegram (когда понадобится)

Сейчас записи ведутся вручную. Когда захочется получать заявки в Telegram:

1. Создать бота через [@BotFather](https://t.me/BotFather), получить токен.
2. Написать боту любое сообщение и узнать свой `chat_id`
   через `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
3. Дальше два пути:
   - **Без кода** — подключить Formspree к Make/Zapier, они перешлют заявку в Telegram.
   - **С кодом** — небольшая функция на Netlify/Vercel, которая принимает форму и
     дёргает `sendMessage`. Токен бота нельзя класть в `main.js` — он виден всем.
