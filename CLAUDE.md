# CLAUDE.md

Ориентир для Claude Code при работе с этим репозиторием.

## Что это

Сайт-визитка психолога Юлии Нохриной (Новосибирск, очно и онлайн). Одна страница
плюс страница политики конфиденциальности. Цель сайта — чтобы человек узнал себя
в описании проблем, понял, чем Юлия может помочь, и оставил заявку.

**Живой сайт:** https://mafusailn.github.io/nokhrina-psy/
**Репозиторий:** https://github.com/MafusailN/nokhrina-psy

## Технические решения

Чистые HTML + CSS + JS. **Ни сборки, ни фреймворков, ни npm — и не добавлять.**
Сайт должен открываться двойным кликом по `index.html` и деплоиться копированием
папки. Это осознанное ограничение: сайт будет жить годами без обслуживания,
и владелец должен уметь поправить в нём текст блокнотом.

Единственная внешняя зависимость — шрифты Google (Cormorant Garamond + Manrope).
При отсутствии интернета деградируют до системных Georgia / Segoe UI.

## Структура


## Дизайн

Палитра снята с личной фотоленты Юлии: сумеречные кадры, вода, закаты, силуэты.
Отсюда тёмный фон и янтарный акцент — сайт намеренно **не** в пастельной гамме,
типовой для психологов.

Все цвета живут в токенах `:root` в начале `styles.css`. Менять цвета только там,
хардкод значений по файлу не разводить. Исключения — намеренные rgba-подсветки
(свечение за hero, тени кнопок), они привязаны к `--accent` по значению.

Типографика: заголовки — антиква Cormorant Garamond, текст — Manrope.
Скругления `--r`, тень `--shadow`.

## Форма записи

Отправка идёт через [FormSubmit](https://formsubmit.co) — без регистрации и без
своего сервера, заявка приходит письмом на почту. Настройки в начале
`assets/js/main.js`, объект `CONFIG`.

Раньше использовался `mailto:` — от него отказались намеренно: он открывает
почтовый клиент, требует от посетителя лишних действий, а на телефонах без
настроенной почты заявка теряется молча.

Адрес требует разовой активации по ссылке «Activate Form» из письма (см. README).
После неё FormSubmit выдаёт «скрытый» endpoint — его стоит подставить вместо
почты в открытом коде, чтобы адрес не собрали спам-боты.

**Форму нельзя проверять локально**: FormSubmit отклоняет страницы, открытые
как `file://`. Только на опубликованном сайте. Оба состояния настройки
(не активирована / открыта с диска) форма показывает отдельными сообщениями —
не путать их с обычным сбоем связи.

Защита от ботов — скрытое поле `_gotcha`. При ошибке сети форма показывает
ссылки на Telegram и почту, чтобы человек не потерялся.

Токен Telegram-бота в `main.js` класть нельзя — файл публичный. Если понадобится
дублирование заявок в Telegram, только через Make/Zapier поверх Formspree или
через серверную функцию.

## Фотографии

`portrait.jpg` взят из объявления на Avito (Avito отдаёт только 640×480), обрезан
под 4:5 со сдвигом влево — так срезан водяной знак. Разрешение маловато, при
случае заменить оригиналом от 1200×1500, имя файла сохранить.

`about.jpg` собирается скриптом из `about-raw.jpg`: обрезка 4:5, нижняя часть с
кружками сторис и реакциями отсечена. Координаты рамки зашиты в начале скрипта.

```powershell
powershell -ExecutionPolicy Bypass -File tools\crop-avatar.ps1
```

**Скрипты PowerShell сохранять в UTF-8 с BOM** — PowerShell 5.1 читает `.ps1`
как ANSI и ломается на кириллице в комментариях.

## Публикация

GitHub Pages собирается из ветки `main`, папка `/`. Деплой = обычный push,
сайт обновляется за минуту-две.

```powershell
git add -A
git commit -m "что изменено"
git push
```

Важное требование владельца: **исходники должны оставаться и в папке проекта,
и на GitHub** — правки делаются локально и сразу пушатся, а не наоборот.

## Правовые ограничения

**Не размещать на сайте ссылки на Instagram и другие сервисы Meta** — деятельность
организации признана в РФ экстремистской, ресурс заблокирован, а ссылка со своего
сайта подпадает под запрет рекламы на таких площадках. Даже упоминание словом
потребовало бы обязательной пометки. Telegram, Max, VK, WhatsApp таких ограничений
не имеют.

## Правила текстов

Тексты писались за Юлию по смыслу её объявления на Avito и ждут её вычитки.
Голос спокойный, без давления и продающих приёмов, без обещаний результата.
Обращение на «вы» со строчной. Не использовать «психологические» штампы
(«проработать травму», «выйти из зоны комфорта»), не ставить диагнозы,
не обещать конкретных сроков излечения.

Фактура, которую менять нельзя без подтверждения: КПТ + телесно-ориентированная
терапия, 2000 ₽ за 60 минут, НГУ (клиническая психология, 2026), Школа ЧК
(КПТ, 105 ч, 2025), Сибирский институт (ТОП, 88 ч, 2025), очно на обоих берегах
Новосибирска и онлайн.
